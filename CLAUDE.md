# Contractor Finance Institute

Educational platform for contractor financial education.

## Purpose

Training and educational content for contractors learning financial management.

## Tech Stack

- Next.js (App Router)
- Tailwind CSS
- Vercel deployment

## Development

```bash
pnpm dev      # Start dev server
pnpm build    # Production build
pnpm lint     # ESLint
```

## Deployment

Auto-deploys to Vercel on push to main.
